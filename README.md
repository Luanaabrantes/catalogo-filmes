# Catálogo de Filmes — Tom Hanks

Projeto desenvolvido para a disciplina de Introdução à Computação em Nuvem (ISW055).

Professor: @siriani

## Sobre o projeto

Aplicação web que consulta filmes com Tom Hanks por meio da API do TMDB.

O sistema permite:

- cadastro de usuários;
- login e logout;
- consulta de filmes;
- visualização de título, pôster e sinopse;
- favoritar filmes;
- adicionar comentários;
- persistência de favoritos e comentários no MariaDB;
- separação dos dados por usuário.

## Tecnologias utilizadas

- Node.js
- Express
- JavaScript
- HTML
- CSS
- MariaDB / MySQL
- TMDB API
- Docker
- Portainer

## Variáveis de ambiente

As credenciais e tokens não são armazenados no repositório.
